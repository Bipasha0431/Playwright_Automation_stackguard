# Login Test Plan

## Feature summary

The Swag Labs login page lets a user sign in with a username and password and, on success, lands on the product page. This plan covers valid sign-in with the standard account and the rejection of the locked-out account, rejection of invalid or empty input with the exact error messages, the error banner, the password field, and the session after sign-in.

## Application URL / environment

- URL under test: https://www.saucedemo.com (public production demo)
- Every scenario starts in a fresh browser context (no cookies, no stored session) on the login page.

## Credentials used

- standard_user, locked_out_user
- Both share the same password: secret_sauce
- Invalid values (wrong_user, wrong_pass, etc.) are made up for rejection scenarios only.
